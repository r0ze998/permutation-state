## 6. Notes for the next owners

- **W6-D:** run the matrix after each web change. `SCREENS_ONLY=report,march` and `SCREENS_VIEWPORTS=360` narrow it. A new screen needs a scene in `scenes.mjs`, reached through the page's own controls. When the recorded fixtures land, `world.mjs` can serve them instead of the synthetic world; `fixtures.screen.mjs` checks that the page accepts them. The scripted onboarding run (E7, 41040) can reuse `checks.mjs`.
- **Everyone touching the page:** the CSP (`style-src 'self'`) forbids style attributes in markup, so use classes. CSSOM (`el.style.setProperty`) is allowed, which is how `--vvh` is set. Keep interactive elements ≥ 44 px on phones: the matrix fails otherwise.
