## 1. ひとことで

1. **勢力図が動かない原因は、ルールそのものでした。** 最初の拠点は自分の勢力の扇形（ウェッジ）にしか置けません。さらに、地図の色は「その州で一番多く拠点を持つ勢力」で決まっていました。なので M1 では、色が変わる手段がありませんでした。
2. **拠点の奪い合いを足すだけでは、まだ動きません。** 包囲・占領・奪取をすべて入れても、7日・1,000人のシーズンで色が変わる州はほぼ0でした【シミュ】。3つの別々の実験で、結果は同じでした。
3. **解決策：各州に「砦（とりで）」を1つ置き、地図の色は砦の持ち主で決めます。** 砦は勢力のもので、個人のものではありません。だれの家も失われずに、地図が動きます。
4. シミュレーターでは、人が混ざった1,000人・7日間で次の結果でした【シミュ】：
   - **1日に約28州の色が変わる。マーチ（7州のまとまり）の旗は1日に約8回変わる**
   - **州の約3分の1が、一度は持ち主が変わる**
   - **1つの勢力が強くなりすぎない**（終了時の最大でも約18%）
   - ただし注意が2つあります：
     - シミュレーターのボットは、M1 の実際のボットよりずっと頻繁に動きます（シミュは1日24回動く設定。M1 の実際のボットの行軍は、1体あたり1日0.24回でした【実測】）。最初の段階で、実際の頻度に合わせたボットで測り直します。
     - **統率の取れた勢力（全員で作戦を合わせる勢力）が強くなりすぎないかは、まだ検証していません。** これも最初の段階で測ります。
5. **動き方の正直な見通し：**
   - 動くのは主に勢力の境目で、行ったり来たりします（奪った砦の約4割は、3日以内に取り返されます）。
   - 勢力の大きさは、最後まで15〜20%くらいのままです。3倍の人数の勢力でも、約18〜21%にとどまります。
   - 中核地の内側は、最後まで変わりません。
6. **「最初の拠点は絶対に奪われない」（D9）は守ります。** 調べた結果、このルールは地図が動かない原因ではありませんでした。（ただし、長いシーズンで長く放置した場合の例外が1つあります。§4）
7. お金（参加費・賞金）は入れません（M2）。政治（大臣・宣戦・休戦）も入れません（M3）。その代わりの「初期設定」で動かします。

## 2. 遊びとしてのルール

### 2.1 砦（勢力図を動かす主役）

- 2周目より外の各州に、砦が1つあります。最初は、その州がある扇形の勢力が持っています。守備兵は100人です。
- **奪い方：** 敵の勢力が砦のマスを **12時間（72ベル）続けて押さえる** と、砦はその勢力のものになります。その間、砦の持ち主側の部隊がマスに1つも立っていないことが条件です。
- **守り方：** 自分の勢力の部隊を1つでも砦のマスに送れば、相手の進み具合は0に戻ります。
- 奪いに来たことは、最初の1ベルから全員に見えます。守る側には、ほぼ12時間の余裕があります。
- 奪った直後の砦は、**48時間は奪い返せません**（取り合いが延々と往復するのを防ぐため）。
- **奪った側の一番大きい部隊が、兵の半分を砦の守備に残し、残りを連れて家に帰ります。** ほかの部隊はその場に残ります。（v1.0 は「マスにいる全部隊の半分ずつ」でしたが、それだと守備兵が上限の3万人を超えて、その州の戦いが永久に止まる不具合がありました。シミュレーターで測ったのと同じ「1部隊だけ」に直しました。）
- 砦に残った部隊は、そこからさらに先へ行軍できます。前線を押し進められます。
- **砦は点数にも資源にもなりません。地図の色だけ** です。そのため、
  - 大きい勢力がますます強くなる「雪だるま」が起きにくい
  - 自動プレイ（ボット）が得をすることもない
- **はっきり言っておくべき弱点：人には、砦を取る理由がまだありません。** ボットが砦を攻めるのは、そうプログラムされているからです。シミュレーターも「攻めるかどうか」をサイコロで決めています。
  - 今回の対策：点数にはならない「表示だけ」のごほうびを付けます。個人ランキング（取った砦の数、砦を守った時間）と、シーズン記録の称号です。
  - 砦を点数に入れるか（マーチの旗を持った時間を少しだけ点数にする案）は、最初の段階で測ってから決めてもらいます（§6 の14番）。
  - 参考：砦への関心を半分にしても、28日シーズンの動きはほとんど減りませんでした（マーチの旗の変化 1日3.0回 → 2.9回）【シミュ】。4分の1の場合は、これから測ります。

### 2.2 拠点の奪い合い（個人の得と損）

- **包囲：** まず封印された行軍（行き先は着くまで秘密）で、敵の拠点のマスに乗り込み、そこで勝ちます。そのマスに残った部隊だけが「包囲の角笛」を鳴らせます。
- **角笛を鳴らせるのは、そのマスで一番大きい部隊の持ち主だけ** です。v1.0 では「先に取引を通した人」が奪取の権利を取る早い者勝ちでした。一番兵を出した人が権利を持つ形に直しました。
- **完成の条件：** 6時間以上、相手の「夜の休み時間（ヴィジル、8時間）」以外の時間にマスを押さえ続けること。
- **守る側：** 1ベルでもマスを取り返せば、包囲は失敗です。
- **かけ金：** 包囲には **金貨500** をかけます。
  - 守る側が包囲を破れば、かけ金は守った側のものです。拠点は6時間、**その勢力からは** 包囲されなくなります（ほかの勢力からは包囲されえます）。
  - 攻める側がただ立ち去っただけなら、かけ金は消えます。仲間同士で「わざと失敗する包囲」をして守りの時間を稼ぐずるを防ぐためです。
- **包囲は1人1日2回まで** です。

### 2.3 包囲が成功したら

- **最初の拠点 → 占領**
  - 持ち主は変わりません（D9）。
  - **占領で移るのは点数（ドミニオン）だけで、地図の色は変わりません。** 地図の色（砦）と点数の順位は、食い違うことがあります。
  - 占領は最長で、7日シーズンなら12時間、28日シーズンなら48時間です。
  - **終わったあとの休み（同じ長さ、包囲されない時間）は、占領していた勢力に対してだけです。** しかも、期限切れか、持ち主の側が取り返したときだけ付きます。占領した側がただ立ち去っただけなら、休みは付きません。（別の勢力にいる自分の分身に占領させて、休みを稼ぎ続けるずるを防ぐためです。）
- **2・3番目の拠点、自由都市 → 奪取**
  - 包囲を始めるときに、自分の拠点の「枠」を1つ予約します。だから成功すれば **必ず奪取** になります。（v1.0 にあった「破壊」はなくしました。あとから処理する順番で、奪取か破壊かが変わってしまう問題があったためです。）
  - 拠点ごと攻めた人のものになります。守備兵と訓練済みの兵はなくなります。
  - **早すぎる奪い返しは点数になりません。** 前の持ち主が持っていた時間が短い（7日シーズンで1日未満、28日で2日未満）と、点数に数えず、蔵の中身も消えます。同じ人が2つの勢力に分身を置いて、取ったり取られたりして点数を稼ぐずるを防ぐためです。
  - 奪われた人の遠征中の部隊は、最初の拠点に帰ります。
  - 奪われた人の、ほかの場所にいる部隊は、**本人が家に戻すまで、その場で自分の勢力のために戦い続けます。** 奪った側や他人が勝手に帰らせることはできません。

### 2.4 自由都市と前哨地

- **自由都市：**
  - 4周目より外の各州に1つずつ、だれのものでもない町（守備兵300）を最初から置きます。期限で消えることはありません。
  - 奪えば自分の2・3番目の拠点になります。
  - 放置された拠点は、v1.0 では自由都市になる案でしたが、**M1 と同じく普通の空き地に戻す** ことにしました（他人の戦利品にしないため）。
- **前哨地（2・3番目の拠点）：**
  - 最初の拠点が「町」以上に育った人が建てられます。
  - 建てられるのは、自分の拠点から3州以内で、中核地の外で、**自分の勢力がまだ半分を押さえていない州** だけです。前線に建てさせて、奪い合いの場所を作るためです。

## 3. 地図で何が変わるか

- **地図の色＝州ごとの砦の持ち主** です。
- **マーチの旗＝その中の砦の過半数を持つ勢力** です。地図の色になるのは旗だけです。点数の首位は、順位表にだけ出します。
- 7日間のデモで見えるもの：
  - 初日から、扇形の境目で砦の取り合いが始まります。
  - 2日目以降は、包囲・占領・前哨地が加わります。
  - 中核地の内側は、最後まで変わりません。
- 「地図が動いた」を、合格・不合格の **数字の条件** にします（契約書の基準10）。主な条件はこうです：

  | 条件 | 目安 |
  |---|---|
  | 6ベル以上続いた色の変化 | シーズン合計60回以上 |
  | 毎日の変化 | 2日目から7日目まで、毎日1回以上 |
  | 一度でも持ち主が変わった州 | 15%以上 |
  | 2日目の終わりと最後で色が違う州 | 10%以上（7日間での値は、最初の段階で測って確かめます） |
  | 勢力の偏り | 終了時に1つの勢力が30%以下、どの勢力も8%以上 |
  | 最初の拠点の持ち主が変わった回数 | 0回 |

  シミュレーターの値と比べた余裕は、v1.0 で書いた「4〜6倍」ではなく **約2倍** です。合否はこの固定の目安で決め、シミュとの比較は横に並べて報告します。
- ボットが十分に動いているかを、毎晩の試験で直接チェックします（行軍や砦攻めの回数が、シミュの想定の半分を下回ったら不合格）。9時間の本番リハーサルの前に、動きの少なさに気づけます。
- M1 の終了時の「動かない地図」を判定に通すと、**必ず不合格になる** ことも確認します。
- 結果は、7日分の地図を1日ごとに並べた図（`mapmove.svg`）で見られます。
- **画面での見え方について：** 地図の絵（アート表示、いまの標準）の色付けは、デザイン担当（別チャット）のファイルが「拠点の多さ」で塗っています。こちらでは触れないので、砦の色に切り替えるようデザイン担当にお願いします。それまでは、簡易表示（`?art=0`）と `mapmove.svg` で、動く地図を見られます。

## 4. 守られるもの

- **最初の拠点：** 戦いで奪われることはありません。占領されても期限があり、そのあとは休みがもらえます。
  - **例外が1つだけあります（M1 と同じルール）：** 28日シーズンでは、**10日間なにも操作しないと拠点が手放され、空き地に戻ります。** そこに他人が新しく住むことはありえます。
  - 7日シーズンでは、手放されることはありません。（v1.0 では約2.5日で手放される設定で、M1 の7日用の設定より厳しかったので直しました。）3日間放置すると、シールド中でも占領はされえます（奪われはしません）。
  - 放置で家を失うカジュアルな人がどれくらいいるかは、シミュレーターで数えて報告します。
- **中核地**（自分の扇形の2〜3周目）**：** 包囲も砦の奪い合いもありません（M3 で宣戦ができるまで）。どの勢力も消えません。
- **新しく来た人：**
  - 最初の24時間（7日シーズン）はシールドで守られます。
  - 遅れて来た人は、近くにいる勢力の最初の拠点からしか包囲されません。
- **夜：** 1日8時間の休み時間は、包囲が進みません。この時間は、包囲を始めた時点で固定されます。
- **シーズンの終わり：**
  - 終わりまでに完成できない包囲は、始められません。
  - 終わりの時点で続いている包囲は無効になり、かけ金と予約した枠は戻ります。
  - 最後の地図が、そのシーズンの記録になります。

## 7. 正直な見積もり

- **作業量：** 人間のチームなら約46人週（v1.0 は42.5）。6人＋まとめ役1人で約8週間です（50%の確率で8.5週、80%で10.5週）【推定】。
- **AIエージェントの場合：** M1 は約62人週の計画を、約3.5日で終えました【実測：作業履歴】。
  - **5〜8日で終わる見込み** です（50%で約6.5日、80%で約9.5日）【推定】。
  - 7日シーズンの通し試験は1回に約9時間かかります。リハーサル1回と本番2回を見込んでいます。
- **いちばんのリスク：** シミュレーターでは地図が動くのに、本番環境のボットでは動かないことです。
  - M1 ではボットの行軍が1体あたり1日0.24回しかありませんでした【実測】。シミュのボットはそれよりはるかに頻繁に動きます。
  - 対策は3つです：合格の目安を「実際の頻度に合わせたボット」のシミュから作る。毎晩の試験でボットの活動量をチェックする。日ごとにボットとシミュを比べる道具を作る（M1 では作られていませんでした）。
  - それでも足りなければ、原因の調査に1〜3日かかります。
- **作業の順番：** 5段階（ウェーブ）、23の作業単位です。
  - 最初の段階でシミュレーターが「地図が動く」ことを確かめます。確かめるまでは、チェーンのプログラムを作り始めません。
  - 最初の段階は「足すだけ」の変更にして、M1 の部分は一切変えません。（v1.0 のままだと、最初の段階の試験が通らない作りでした。）
  - デザイン担当が使う `codex/frontier` ブランチは、このマイルストーンが終わるまで進めません。デザイン担当のいまの画面（停止中の M1 の画面を見ている）が壊れないようにするためです。
- **安全面の約束：**
  - ネットへのプッシュ、devnet・mainnet への送信、新しいインストールはしません。
  - 使うポートは 41300〜41999 だけです（デザイン担当向けの見本データは 41900）。
  - いま停止中の M1 の画面（41000〜41099）と、デザインのチャット（41041）には触りません。
  - デザイン担当のファイルにも触りません。（確かめたところ、触ってはいけないファイルは v1.0 の一覧より多かったので、一覧を広げました。）

## 8. ついでのご質問への答え

### 8.1 AIエージェント：どのモデルで、費用はだれが払うか

- **ゲーム内のボットと運営の隠れプレイヤー（シェイド）の「判断」は、AI（言語モデル）を使いません。** 決まった手順で動くプログラムで、費用はパソコンの計算時間だけです。今回の奪い合いの作戦（どの砦を、いつ、だれと攻めるか）も、同じく決まった手順で計算します。
- **ネット上の手数料：** 中継サーバー（運営）が、人もボットも区別せず立て替えます。今回の試験はすべて手元のローカル環境なので、実際のお金はかかりません。
- **いま実際にAIを使っている場所（旧ゲーム v9）：**
  - 「助言役」：Claude Haiku 4.5。運営の APIキー で、運営が払います。
  - 見本のAIプレイヤー：Claude Sonnet 5。動かした人が自分で払います。
- **AIエージェント計画（`docs/frontier/ai-agents/`。計画だけで、まだ作っていません）では：**

### 8.2 x402 の役割

- x402 は「**ネットの1回のやりとりの中で、『お金が必要です』→『払いました』→『参加完了』までを済ませる仕組み**」です。HTTP にもともとある「402 Payment Required（支払いが必要）」という返事を、本当に使えるようにしたものです。
- このゲームでは、**参加の申し込みそのものが支払いになります。** 具体的にはこうです：
  1. AI でも人のウォレットでも、まず普通に「参加したい」と送る。
  2. 中継サーバーが「402：支払いが必要です」と返す。中身は「参加費がいくらか（USDC で約10ドル）、どこへ、どう払うか」。
  3. 申し込む側は、**ゲームの参加手続き（Join）の取引に、自分で署名** する。この取引には参加費（と、希望すれば月桂冠の賭け金）が入っています。お金はシーズンの預かり口座に入り、**最初の拠点が確定するまで預かり** になります。
  4. その署名付きの取引を付けて、もう一度送る。
  5. 中継サーバーは、取引が決まった形か（許可リスト）を確かめ、自分の手数料の署名だけを足して送る。**中継サーバーは金額も宛先も変えられません**（もう署名済みだから）。
  6. 「200：参加完了」が返る。
- **良い点：**
  - 特別な道具なしで、AIエージェントも人も、まったく同じ道で参加できます。AIが自分でゲームを見つけ、自分で参加費を払い、人の手なしで遊べます。
  - 運営のボット（シェイド）も同じ道を通るので、お金の流れから「だれがボットか」を見分けにくくなります。
  - AI 側の道具には、人が決めた「1シーズンで使ってよい上限額」を付け、それを超えるときは人に確認します。
- **今回（奪い合いのマイルストーン）では使いません。** 参加は無料だからです。お金が入る M2 で戻ってきます。その前に、「強いAIが有利になりすぎないか」の試験に通ることが条件です。

## 9. レビューで直したこと（v1.0 → v1.1）

26件の指摘を、実際のコードと実験結果で1件ずつ確かめました。すべて本当の問題でした。そのうち2件は一部が事実と違い、5件は指摘よりも深刻でした。

**重大（このままだと作れない、またはゲームが壊れる）**
- 砦の守備兵が上限を超えて、州の戦いが永久に止まる → 「一番大きい1部隊の半分」に直しました（シミュと同じ）。
- 最初の段階の試験が、作りの都合で絶対に通らない → 最初の段階は「足すだけ」の変更にしました。M1 のルールの指紋（ハッシュ）も変わりません。v1.0 の変更だと、M1 の野営地の戦い方まで変わるところでした（指摘より深刻）。
- 人に砦を取る理由がない → 本当です。表示だけのごほうびを付け、点数化は測ってから決めてもらいます。ただ「動きはボットへの命令の結果にすぎない」という点は一部違います。関心を半分にしても、動きはほぼ変わりませんでした。

**ずる・不公平の穴**
- 他人が、敵の守備部隊を好きなときに家へ帰せた → 本人だけが帰せるようにしました。
- 角笛が早い者勝ちだった → マスで一番大きい部隊の持ち主だけにしました。
- 奪取か破壊かが、あとの処理の順番で決まっていた → 枠を開始時に予約し、破壊はなくしました。拠点の点数の重みまで処理の順番で変わる問題も見つけて、一緒に直しました（指摘より深刻）。
- 分身を使った「休み」稼ぎ → 休みは相手の勢力に対してだけにしました。v1.0 の「守った後の6時間の休み」も分身で稼げたので、同じく直しました（指摘より深刻）。
- 分身同士の奪い合いで点数稼ぎ → 早すぎる奪い返しは点数なしにしました。
- 包囲中に拠点の状態が変わって処理が詰まる → そうならない決まりを7つ足しました。
- 包囲の取引の計算量に根拠がない → 計算に上限を付けました。

**数字・試験・説明の見直し**
- シミュのボットが実際より動きすぎ → 実際の頻度で測り直し、毎晩チェックします。
- 勢力の大きさがずっと変わらない → 本当です。これは「雪だるまを防ぐ」設計どおりです。ただし「取った砦を前線基地にできない」は間違いでした（チェーン上はもうできます。シミュだけができていませんでした）。
- 7日シーズンで家を失う条件が、M1 より厳しかった（指摘より深刻） → 7日の間は手放されないようにしました。
- デザイン担当のファイルは、一覧より多く変わっていた（指摘より深刻） → 一覧を広げ、こちらは新しいファイルだけで作ります。
- 「地図の色」と「点数の首位」の2つの支配がまぎらわしい → 地図の色は砦だけ。点数は順位表だけ。
- そのほか、試験の条件（処理の遅れや競合の許し方、試験用の短い時間設定）、旧データの読み方、合格の目安の余裕（「4〜6倍」→ 実際は約2倍）を直しました。
