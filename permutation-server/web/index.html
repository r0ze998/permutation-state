HOW TO PLAY · 遊び方

ひとつの世界で、あなたの文明を率いる。

6つの文明が同じ地図を共有しています。あなた以外の5文明はルールで動くボット（AGENT表示）です。30秒ごとの「ティック」で、全員の命令が同時に解決されます。

  1. 地図を選んで調べる。都市・部隊・土地をクリックすると右のパネルに詳細と、できること・できない理由が出ます。
  2. 命令は「枠」を使う。1ティックの枠は3＋都市数（最大8）。使わなかった枠は最大4ティック分まで繰り越せます。枠は人間もボットも同じです。
  3. 命令は下書き→確定。下の命令ドックに貯めて「確定」。締切3秒前には自動で確定します。ティック内の送信順は結果に影響しません。
  4. 見えるのは視界の中だけ。部隊と都市のまわり2マス（斥候は3、丘陵は+1、山の向こうは見えない）。一度見た都市と国境は霧の中でも「最後に見た姿」で残ります。ボットも同じ霧の中で判断しています。
  5. 勝ち方は3つ。覇権（領土と占領）・科学（スターゲート3段階）・協調（侵略しない期間の繁栄と都市国家）。いずれも期間の積み上げで決まります。
